# MySQL 50 Practice Questions for Data Analytics

## 📌 About This Project

This project contains 50 MySQL practice questions focused on strengthening SQL skills for data analytics. It covers essential SQL concepts used to retrieve, analyze, and interpret data.

The goal of this project is to improve SQL problem-solving skills and develop a better understanding of real-world data analysis scenarios.

## 🎯 Project Objectives

- Practice SQL queries using MySQL.
- Strengthen data filtering, aggregation, and grouping skills.
- Understand advanced SQL concepts.
- Solve business-oriented data analysis problems.
- Build a portfolio project to demonstrate SQL skills.

## 🛠️ SQL Concepts Covered

- **Basic SQL:** SELECT, WHERE, ORDER BY, DISTINCT
- **Aggregations:** COUNT(), SUM(), AVG(), MIN(), MAX()
- **Grouping and Filtering:** GROUP BY, HAVING
- **Joins:** Combining data from multiple tables
- **Common Table Expressions (CTEs):** Using WITH to organize complex queries
- **Window Functions:** ROW_NUMBER(), DENSE_RANK(), LAG(), LEAD(), FIRST_VALUE(), LAST_VALUE()
- **Sales Analysis:** Monthly sales, running totals, and moving averages
- **Customer Analytics:** Repeat customers, customer revenue, and first/latest order analysis
- **Conditional Logic:** CASE statements for categorization
